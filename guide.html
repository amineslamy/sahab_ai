دستورالعمل جامع اجرای مجدد زیرساخت و سرویس‌ها پس از ری‌استارت سیستم

آماده اجرا

📌 پیش‌نیازهای دائم روی سیستم

قبل از اجرای هر دستوری، مطمئن شوید نرم‌افزارهای زیر روی ویندوز نصب و آماده به کار هستند:

🐳 Docker Desktop
برای مدیریت دیتابیس‌ها (با قابلیت پشتیبانی از WSL 2)
🦙 Ollama
برای اجرای مدل هوش مصنوعی محلی (qwen2.5:3b)
🐹 Go Compiler
زبان برنامه‌نویسی Go (نسخه ۱.۲۱ یا بالاتر)
📦 Git
برای مدیریت سورس‌کد و همگام‌سازی گیت‌هاب

🔄 مراحل راه‌اندازی سیستم پس از ری‌استارت

۱

حصول اطمینان از اجرای سرویس‌های پایه

  • Docker Desktop را اجرا کنید و صبر کنید تا آیکون آن در نوار وظیفه (Taskbar) حالت سبز و فعال پیدا کند.
  • مطمئن شوید Ollama در حال اجراست (معمولاً پس از ری‌استارت به‌طور خودکار در پس‌زمینه بالا می‌آید یا می‌توانید آن را از Start اجرا کنید).
۲

روشن کردن سرویس‌های دیتابیس (Docker)

یک ترمینال CMD باز کرده و دستورات زیر را وارد کنید:

cd /d D:\PY\sahab_ai
docker compose --profile local up -d

برای اطمینان از سلامت دیتابیس‌ها (Neo4j, Redis, LibSQL) دستور زیر را بزنید:

docker compose ps
۳

اجرای وب‌سرور پروژه (Go)

در همان ترمینال CMD دستور زیر را بزنید تا برنامه اصلی روشن شود:

go run main.go
با مشاهده این پیام در ترمینال، سرور آماده پاسخ‌گویی است:
🚀 وب سرور سحاب AI آماده است: http://localhost:8081
۴

دسترسی به رابط کاربری (UI)

مرورگر اینترنت خود را باز کرده و به آدرس زیر بروید:

http://localhost:8081

⚡ خلاصه‌ی یک‌خطی جهت اجرا (برای استفاده سریع)

می‌توانید تمام مراحل فوق را در یک خط دستور CMD اجرا کنید:

cd /d D:\PY\sahab_ai && docker compose --profile local up -d && go run main.go
